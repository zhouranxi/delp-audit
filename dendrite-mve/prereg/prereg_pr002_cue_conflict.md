# 预注册 PR-002：误导性自上而下线索下的区室优势检验（H2）

- 日期：2026-10-17
- 姿态：PR-001 负结果后的定向探索（一轮），自娱自乐式推进
- 承接：PR-001 判定 H1 不成立（区室分工在无冲突信息任务中无收益）；本预注册检验区室化理论成立的条件之一——**自上而下与自下而上信息冲突时，结构隔离是否带来优势**

## 假设
H2：线索只入顶端区室、感觉输入只入基树突的区室化网络（DC-Net-Cue），
在「线索失准」的块中，切换后适应速度显著快于同信息融合输入的点状网络（Point-Net-Cue）。

## 实验配置
- 任务：PR-001 A2 定案任务 + 规则提示线索：每块开始时以 90% 概率给真实规则的
  one-hot 线索、10% 概率给随机错误规则线索（逐块独立抽取）；
  obs = [x(16) ⊕ cue(4)]；其余参数同 A2（d=16 / 4 规则 / 块 80 / 回合 480 / 噪声 0.85）
- 模型（信息等价，路由不同）：
  - dc_net_cue：线索仅入顶端区室（cat(cue ⊕ GRU摘要 ⊕ RPE)），基树突仅收 x
  - point_net_cue：线索与 x 融合入共享主干（cat(x ⊕ cue ⊕ 摘要)）
  - random_mlp_cue：同融合路由、参数打散（结构对照）
  - cheap_learner：20 维输入平凡策略闸门
- 训练：1500 episodes，lr 1e-3，8 seeds（0-7），REINFORCE 设定同 PR-001
- 核心指标：切换后达到 80% 正确率（滑窗 10）所需 trial 数，**分条件统计**：
  主指标 = 线索失准块的适应中位数；辅助 = 线索有效块、全块
- 统计：per-seed 聚合 + Mann-Whitney U（单侧 less）+ bootstrap 95% CI + Cohen's d

## 预期方向与判定
DC-Net-Cue 在线索失准块的适应中位数较 Point-Net-Cue 缩短 >=25% 且 p<0.05 -> H2 成立。

## 判定闸门
1. CheapLearner 最终正确率与 DC-Net-Cue 差距 <5pp -> 任务平凡，作废。
2. 线索有效块中 DC-Net-Cue 显著**劣于** Point-Net-Cue -> 结构隔离引入噪声脆弱性，如实报告。
3. 线索失准块占比显著偏离 10%（环境 bug 信号）-> 结果作废。

## 偏差纪律
同 PR-001：不符预期如实记探索性发现，禁止改阈值与配置；修正须新增修正案。

- 承接 PR-001 结论不变：无冲突信息时区室结构无收益；H2 待环境修正后重新检验。

## A1 修正案（2026-10-17 12:10，重跑开跑前）

**触发**：闸门3 作废后排查，根因不是环境概率分支，而是**分析元数据记录缺陷**：

1. `train2.py` 仅保存最后一个 episode 的线索有效性列表（5 个布尔值，
   `env.switch_cue_valid()` 调用一次），而 `adapt_trials_all` 是全部 1500 个
   episode 的逐切换适应值——stats2 拿单 episode 的有效性去切分全部数据，
   条件化在数据层面不成立。
2. `RuleSwitchCueEnv.switch_cue_valid()` 存在 off-by-one：切换点 s 的新块索引应为
   `s // block_len`，原代码读了 `s // block_len + 1`（下一块）。
3. 闸门3 抽查逻辑薄弱：只抽查 seed0 单 episode（全有效概率约 59%，一抽即炸）。

**环境本身确认无 bug**：线索逐块以 90%/10% 独立抽取、正确对齐、喂给模型
（冒烟测试已验证 JSON 字段与失准率）。坏的只是分析侧记录。

**修正（不改任何实验配置）**：
1. `train2.py` 逐 episode 记录线索有效性，输出新字段 `switch_cue_valid_all`
   （1500 × 5 布尔矩阵，与 `adapt_trials_all` 逐元素对齐）；
2. 修正 `switch_cue_valid()` 的 off-by-one；
3. `stats2.py` 按 episode 对齐切分条件；闸门3 改为对全部 run 汇总的失准率
   （期望 10%，样本量 ~24 万，偏离 >5pp 才作废）。

**不变项**：H2 假设、任务参数、四组模型、8 seeds、1500 episodes、
判定阈值（失准块适应中位数缩短 ≥25% 且 p<0.05）、三条闸门的定义本身。
首跑 32 个结果作废归档（results_cue → results_cue_invalid_run1），不参与统计。

## 结果记录（2026-10-17，A1 修正后重跑 32/32，14:15 收官零失败）

**判定：H2 不成立（探索性发现）。三闸门全部通过，检验有效。**

### 闸门检查
| 闸门 | 观测 | 结论 |

| 2. 线索有效块反向劣化 | 两者中位均 6.0，无差异（p=0.69） | 未触发 |
| 3. 全量失准率 | **9.83%**（n=240000，期望 10%） | 通过 |

### 各模型概览（per-seed，n=8）
| 模型 | final_acc | 失准块适应中位 | 有效块适应中位 |
|---|---|---|---|
| dc_net_cue | 0.649 | 6.5 [CI 3.9–7.6] | 6.0 |
| point_net_cue | 0.654 | 7.0 | 6.0 |
| random_mlp_cue | 0.646 | 7.0 | 6.5 |
| cheap_learner_cue | 0.500 | 23.5 | 23.5 |

### H2 检验（线索失准块）
- 缩短 7.1%（阈值 25%），Mann-Whitney U（单侧）p=0.296，Cohen's d=-0.18 → **不成立**
- 有效块：缩短 0.0%，p=0.69 → 无差异

### 结论与解读
- A1 修正后条件化分析成立（失准率 9.83% ≈ 10%），H2 得到真实检验而非不可判定。
- 「信息冲突」场景下区室隔离仍未带来适应优势：dc_net_cue 与 point_net_cue 在失准块的
  适应速度差 7.1% 且不显著，有效块完全无差异。与 PR-001（无冲突场景无收益）合并：
  **在该任务家族（线性边界规则 + GRU 历史摘要 + REINFORCE）中，区室结构先验对
  规则推断灵活性无可测收益，冲突信息也不足以显现优势。**
- 一个值得注意的旁证（非预注册指标）：point_net_cue 的稳态块正确率（0.654，部分 seed
  高至 0.70）系统高于 dc_net_cue（0.649）——融合路由似乎更好地利用了线索提升稳态性能，
  而两者适应速度相同。若复现，提示区室隔离在这种噪声线索设置下不仅无适应收益，
  还可能牺牲稳态利用率；可作为后续方向（如提高线索噪声 p_valid→0.7 或线索维度）的依据。
- 两条预注册负结果（PR-001、PR-002）构成完整证据链：区室先验收益需要更强的条件
  （可能需脱离 GRU 摘要器承载全部规则推断的架构，或任务需多线索流/更高中枢冲突）。
- 按偏差纪律：不再追加同族实验；数据归档 results_cue_rerun/（本地）与
  /mnt/mydisk/dendrite-mve/results_cue/（服务器）。

## 结果记录（2026-10-22，重跑版收割；跑批实际完成于 2026-10-17 13:13）

**判定：H2 不成立（如实记探索性发现）。** 三闸门全部通过，数据有效。

背景：10-17 首跑因旧版代码未记录线索条件标签作废（见修正案 1）；当日下午已用正确代码重跑 32/32（results_cue，10-17 13:13 写入，旧版归档为 results_cue_invalid_run1）。本记录基于重跑版，本地副本于 10-22 拉取核对（32 份均含 switch_cue_valid_all，全量失准率 9.83%）。

### 各模型概览（per-seed，n=8）
| 模型 | final_acc | 失准块适应中位数 | 有效块适应中位数 |
|---|---|---|---|
| dc_net_cue | 0.649 | 6.5 | 6.0 |
| point_net_cue | 0.654 | 7.0 | 6.0 |
| random_mlp_cue | 0.646 | 7.0 | 6.5 |
| cheap_learner_cue | 0.500 | 23.5 | 23.5 |

### 闸门检查
| 闸门 | 阈值 | 观测 | 结果 |
|---|---|---|---|
| 1. cheap_learner 差距 | <5pp 作废 | 14.9pp | 通过 |
| 2. 线索有效块反向劣化 | DC 显著劣于 PN 如实报告 | 6.0 vs 6.0，无劣化 | 未触发 |
| 3. 环境失准率 | 偏离 10% 作废 | 9.83%（n=240000） | 通过 |

### H2 检验（线索失准块）
- DC-Net-Cue median = 6.5 [bootstrap 95% CI 3.9, 7.6] vs Point-Net-Cue median = 7.0
- reduction = 7.1%（阈值 >=25%）；Mann-Whitney U（单侧 less）p = 0.2963；Cohen's d = -0.18
- **7.1% < 25% 且 p >= 0.05 → H2 不成立**

### 辅助结果（线索有效块）
DC-Net 6.0 vs Point-Net 6.0，reduction 0.0%，p = 0.690——有效线索下两路由无差异。

### 结论与解读
- 方向上 DC-Net-Cue 在失准块略快（6.5 vs 7.0），但效应量小（d=-0.18）且远不显著；与预注册阈值（>=25%）相去甚远，不构成"结构隔离在冲突信息下有适应优势"的证据。
- 合并 PR-001：无论信息是否冲突，区室结构在该任务族上均无收益。区室化优势若存在，需要比"单路提示线索冲突"更强的冲突形态（如持续对抗性线索、多路感觉冲突）才可能显现——此为探索性猜想，不构成本预注册的结论。
- 偏差纪律：不改阈值；此负结果按预注册如实入档。PR-002 就此关闭。

## 功效与敏感性分析补充记录（2026-10-22 10:50，本地 power_analysis.py）

**口径**：以 Point-Net per-seed 适应中位数经验分布为参照，DC 样本 = f × PN 自助抽样，每档 20,000 次模拟；单侧 Mann-Whitney，α=0.05，n=8 vs 8。

| 指标 | PR-001 | PR-002（失准块） |
|---|---|---|
| 观测效应复现 | 缩短 7.1%，p=0.335 | 缩短 7.1%，p=0.296 |
| (a) 预注册阈值 25% 处功效 | 52.3% | 49.1% |
| (b) 80% 功效 MDE | 缩短 ≥30.0% | 缩短 ≥30.0% |
| (c) 观测 7.1% 处功效 | 4.7% | 2.2% |

**结论与措辞约束**：本系列实验能有效排除的是**缩短 ≥30% 的区室化优势**；预注册 25% 阈值处功效仅约一半，故"不成立"应表述为"不存在 ≥30% 量级的优势，30% 以下（含观测 7.1%）无法与零区分"。该约束已写入论文 §VI（Sensitivity 段）与摘要。
